VEMLAB Laboratorio virtual de máquinas eléctricas

VEMLAB es un complemento a las prácticas: prepara los ensayos antes de la sesión y contrasta después tus medidas reales. Modelo de régimen permanente con circuito equivalente; las lecturas incluyen un pequeño error de medida (desactivable en ⚙).

Ajustes

Código de práctica

Con un código (p. ej. el de cada grupo) se genera una máquina con parámetros ocultos distintos para cada código. El alumnado debe identificarlos con los ensayos. El profesor puede introducir el mismo código y mostrar los parámetros para corregir.

Datos

Las medidas registradas se guardan en este navegador. Exporta cada tabla a CSV para tu informe.
